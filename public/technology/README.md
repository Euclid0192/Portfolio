# Technology logos

These assets are self-hosted for the portfolio's orbiting technology display. `sources.json` records the upstream asset URL and original brand source for every logo.

- Most SVGs come from Simple Icons (CC0; included license). Brand names and marks remain their owners' property.
- Java, AngularJS, and Playwright use Devicon assets (included license).
- OpenAI uses Lobe Icons (included license).
- Magic UI, BullMQ, Resque, Braze, and Azure Document Intelligence use their project/vendor's published assets.
- SQL, Assembly, CI/CD, and Supertest use Lucide database, CPU, workflow, and badge-check symbols (included license). They represent the technology's function rather than claiming to be official brand marks.
- C/C++ and HTML/CSS badges display both corresponding language logos.

SVG fills are set to the catalog's brand colors for standalone image rendering. Vendor artwork is otherwise preserved.
